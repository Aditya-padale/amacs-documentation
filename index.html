Multi-agent coordination behind one decorator

Wrap any Python function with @amacs and it gets analyzed, split into sub-tasks, run across specialized agents in parallel, and merged into one answer — no framework to adopt, no server to run.

Python 3.9+ MIT License OpenAI · Anthropic · Ollama Sync & async
Get started View on PyPI
research.py
from amacs import amacs

@amacs(max_agents=8, strategy="performance")
def research_task(topic: str) -> str:
    """Conduct comprehensive research on the given topic."""
    return f"Research on {topic}"

# AMACS analyzes, decomposes, runs agents in parallel, merges
result = research_task("Renewable Energy")

What you get from one decorator

AMACS handles the orchestration machinery so the wrapped function stays exactly as simple as it already was.

⚡

Single-decorator API

Wrap any sync or async function with @amacs(...) — no rewrite, no new entry point.

🧩

Automatic orchestration

Task analysis → decomposition → agent selection → scheduling → execution → aggregation, all inline.

🕸️

Communication bus

An in-memory pub/sub store lets agents share intermediate results as they work, with a full audit log.

📡

Adaptive control loop

Watches latency, tokens, and error rate mid-run, and can swap, skip, or drop an underperforming agent.

🔌

Provider-agnostic

OpenAI, Anthropic, and local Ollama models sit behind one interface — no vendor lock-in.

🛠️

Extensible registry

Register custom agent classes, LLM providers, and merge strategies without touching the core library.

Inside a single @amacs call

Seven stages run in-process, every time the wrapped function is called.

01

Task capture

Function name, docstring, and arguments are captured.

→
02

Task analysis

Domain and rough complexity are inferred.

→
03

Decomposition

Split into an ordered sub-task DAG.

→
04

Agent selection

Each sub-task matched to the best-fit agent.

→
05

Scheduling

Parallel waves bounded by max_agents.

→
06

Adaptive control

Optional monitoring, swap, skip, or drop.

→
07

Aggregation

Ordered, joined, validated, returned.

Five layers under the decorator

Everything runs in the same process — no server, no database.

01 · DEVELOPER LAYER

@amacs(max_agents=8, strategy="performance")

Sync/async detection, config parsing, error handling.

↓
02 · ORCHESTRATION CORE

Task Analyzer · Task Decomposer · Agent Selector · Scheduler

Builds and schedules the sub-task DAG.

↓
03 · MULTI-AGENT EXECUTION

Search · Analysis · Writer · Validator · Custom agents

Runs over a shared communication bus.

↓
04 · ADAPTIVE CONTROL (optional)

Monitor → Evaluator → Adaptation Engine → Reconfigurator

Detects and reacts to underperforming agents.

↓
05 · AGGREGATION

Filter → order by DAG → join → final validation

Returns one coherent result to the caller.

import asyncio
from amacs import amacs

@amacs(max_agents=4, strategy="speed", adaptive=True)
async def async_research(topic: str) -> str:
    """Async research with adaptive monitoring."""
    return f"Research on {topic}"

result = asyncio.run(async_research("Climate Change"))
from amacs import amacs, BaseAgent, SubTask, register_agent

class DomainExpertAgent(BaseAgent):
    @property
    def agent_type(self) -> str:
        return "domain_expert"

    def system_prompt(self) -> str:
        return "You are a domain expert in renewable energy..."

register_agent("domain_expert", DomainExpertAgent)

Decorator configuration

Everything is a keyword argument on @amacs(...), validated through Pydantic.

ParameterTypeDefaultDescription
max_agentsint4Maximum concurrent agents (1–64)
strategystr"performance""performance", "cost", or "speed"
adaptiveboolFalseEnables the adaptive control loop
retry_limitint3Per-agent retry limit (0–10)
timeoutfloat120.0Per-agent timeout, in seconds
llm_providerstrNone"openai", "anthropic", "ollama", etc.
llm_modelstrNoneModel name, e.g. "gpt-4o"
skip_non_criticalboolTrueSkip failed non-critical sub-tasks instead of raising
verboseboolFalsePrint agent activity as it happens
return_detailsboolFalseReturn an AMACSResult instead of a plain string
